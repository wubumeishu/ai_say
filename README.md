# Ai SAY

控制比特浏览器指定窗口，将客户消息转成中文，并在右侧显示推荐回复与常用语，为后续自动引流打基础。

## 快速开始

1. 确认比特浏览器客户端已启动，并开启本地 API（默认 http://127.0.0.1:54345）。
2. 安装依赖：

   ```bash
   npm install ws
   ```

3. 启动服务：

   ```bash
   npm start
   ```

4. 打开 http://127.0.0.1:8300 即可使用控制台。

## 核心能力

- 拉取比特浏览器窗口列表（`/api/browsers`）。
- 打开指定窗口并连接 DevTools，开始监控客户消息（`/api/monitor`）。
- 将客户消息翻译成中文，并给出推荐回复（`/api/message`）。
- 常用语一键复制，为自动引流预留扩展点。

## 翻译

- 默认调用 MyMemory 免费接口做自动翻译，无需 API Key。
- 中文原文直接透传，不重复翻译。
- 网络不可用时回退到原文占位，保证界面不卡死。
