# 卡片交互规格 · 最终定稿（2026-10-27 用户 6+4 点敲定）

## 一、核心模型：批量决策 + 后台定时发送队列（决策/发送解耦）

```
卡片 deck（一批候选，按 P1>P2>P4>P5>P6 × 5档在线度 排序）
   │ 按 A/B/C/D 选话术（日语原文+中文译文 双行显示）
   ▼
本张卡进入「待发送」态（state: DRAFTED）→ 显示「待发送」徽章 → 自动滑下一张
   │
   ▼
批量处理完一批（10张全标好「待发送」+ 选中话术）
   │
   ▼
后台发送队列（SendQueue）：按「每20秒±0-10秒浮动」逐条慢慢发
   （出会平台发出后不可撤回；快乐平台可撤回）
```

## 二、一键操作表（字母发/数字处置/决定键自动滑卡）

| 键 | 动作 | 副作用 | 滑卡 | 说明 |
|---|---|---|---|---|
| **A B C D** | 选话术→本张入「待发送」队列 | 弱（只是入队，非真发） | **自动滑下一张** | 选话术=确认本身，不弹二次确认；后台按浮动时间慢慢发 |
| **1** | 标记（加 tag 重点跟进） | 弱 | **不滑卡** | 原地，可继续看 |
| **2** | 拉黑 | **强（平台写）** | 滑 | **拉黑才需二次确认**：按 2 后 1s 内再按 Y 确认 |
| **3** | 暂不回复/跳过 | 弱 | 滑 | 纯跳过 + 挪到队尾 + 记操作日志【操作员A【暂不回复】时间】 |
| **4** | 重新生成 A-D（4条话术） | 无（调 AI） | 不滑 | 原地刷新话术 |
| **5** | 与 AI 对话（不满意话术时微调） | 无 | 不滑 | 弹出 AI 对话框，用自然语言调整话术风格/角度 |
| **6** | 展开/收起 心理分析+策略 | 无 | 不滑 | |
| **→ / Space** | 手动下一张（纯翻页不处置） | 无 | 滑 | |
| **←** | 上一张 | 无 | 滑 | |
| **Y** | 二次确认（仅拉黑用） | 强 | 不滑 | 拉黑按 2 后 1s 内按 Y 才执行 |

**选话术即确认**：不需要额外确认步骤；「待发送」消息支持：
- 修改（再按 A-D 换选/按 4 重生成/按 5 对话微调）
- 撤出（从队列移除，未发的可安全删）
- 出会平台：发出后不可撤回（平台限制），所以「待发送→发送」前可改，发出后只能等下一条
- 快乐平台：发出后可撤回（revokeTextMessage）

## 四、发送队列（SendQueue）节奏与护栏

- **节奏**：全局统一间隔 **每 20 秒 ± 0-10 秒随机浮动**（用户可配 0-10s 浮动范围）
  - 整批 10 张「待发送」≈ 3.5-5.5 分钟发完（不快速连发，防账号违规）
  - 每张卡的实际发送时间 = 上一张发送时间 + 20s + random(0, 浮动范围)
- **待发送队列页**（独立面板）：
  - 列出所有 DRAFTED/QUEUED 状态的卡
  - 可批量：改话术 / 撤出队列 / 改计划时间 / 批量执行
  - 显示每张卡的「已选话术 + 发送计划时间 + 队列位置 + 状态」
- **风控**：
  - 同一账号队列内严格串行（不并发发送，防触发平台频控）
  - 出会平台发出后不可撤回 → 发送前最后一步「待发送→发送」时显示「此平台发出后不可撤回」红字
  - 快乐平台发出后可撤回（3s 内 U 键可撤）

## 五、与 AI 对话（5 键）· 微调话术

当 4 条生成话术都不满意时，按 5 弹出 AI 对话框：
- 可用自然语言描述需求（如"更活泼一点""强调兴趣重合""换个开场角度"）
- AI 基于当前上下文（人设+画像+聊天记录+已选话术）重新生成
- 生成后替换当前卡的 A-D 选项（或追加 E-F 选项）
- 对话历史保留在卡片的 ai.conversationLog 字段（落库）

## 六、数据模型（lead.state 全落库，为全自动化留钩子）

```
LeadCard {
  leadId, platform(ichigo|kairaku),
  customer: { memberId, name, age, city, avatarUrls[], profileFields{}, recruitPosts[] },
  accountSelf: { ... },  // 我方人设（ともね）
  chatHistory: [{ at, dir(send|recv), textJp, textZh }],  // 原文+译文
  ai: {
    analysis: string,        // 心理分析
    strategy: string,        // 应对策略
    talks: [{ key:'A'-'D', intent, textJp, textZh, confidence }],
    conversationLog: [{ role:'user|ai', text, at }]  // 5键对话历史
  },
  state: PENDING → DRAFTED(已选话术「待发送」) → QUEUED(入队列) → SENT(已发)
           / REVOKED(快乐可撤) / SKIPPED(3跳过·挪队尾) / BLOCKED(2拉黑)
  selectedTalk: 'A'|'B'|'C'|'D',   // 选了哪句
  scheduledAt: ISO时间,             // 浮动时间发送计划
  queuePos: 队列位置,               // 3跳过=挪到队尾
  opLog: [{ op:'skip|block|mark|send|edit|revoke', operator:'A', at:'ISO', note }],
  tags: []
}
SendQueue {
  intervalBase: 20000,  // 20秒
  floatRange: [0, 10000], // 0-10秒浮动
  items: [ { leadId, talkKey, scheduledAt, status } ]
}
OperationLog {  // 操作日志（用户点3要求）
  op, operator, leadId, at, note
  // 例：操作员A【暂不回复】2026-10-27 20:35:12 leadId=L123
}
```

## 七、为全自动化留的钩子（现在全设人工，后续切配置即可）

- 半自动：你按 A-D 选话术 → DRAFTED → 入队列 → 后台按节奏发
- 全自动化：把「按 A-D 的人工确认」换成 **GatePolicy 自动选话术**（高置信度+风控绿+白名单动作 → 自动 DRAFTED→QUEUED，其余卡 PENDING 等你）
- 卡片和快捷键完全不变，只改「谁推进 DRAFTED→QUEUED」
- 一键冻结开关常驻：全自动化阶段随时可全转人工（强副作用全卡 DRAFTED）
