# Ai SAY · 项目功能清单（ichigo-console 主链）

> 本文件描述 `http://127.0.0.1:8300/ichigo-console` 控制台的完整能力。
> 项目已瘦身为「出会平台运营控制台」单一主链，多平台骨架（LINE/WhatsApp/FB）与
> 一次性抓取工具（scripts/tools）已移除。

## 1. 客户监控（左栏）
- 比特浏览器窗口连接状态（connBadge 徽章 + 30 分钟轮询收件箱）
- 客户列表：未读标记 / 在线状态 / 地区 / 最近消息（GET /api/console/mailbox、/customers）
- 客户详情：会话历史抓取 + 日文翻译、资料卡（年龄/职业/兴趣/身高）、BBS
- 三层缓存（ichigoCache：收件箱快照 / 会话历史 / 资料卡），避免重复抓取

## 2. 翻译（中栏）
- 日⇄中 LLM 翻译，内容寻址缓存（第二次秒出）
- 常用语（phrases）：增删改查 + 分组 + 使用计数 + 中文译文自动补
  （GET/POST /api/console/phrases），右栏 Ai SAY 面板上方显示「快捷短语条」

## 3. Ai SAY 会话助手（右栏，B v1）
- 真 LLM 对话（POST /api/console/assistant）：组上下文（客户画像 + 最近 12 条消息）
  → 调 ollama 模型 → 返回 { reply, actions }
- 工具白名单：读客户 / 列客户 / 生成话术 / 翻译 / 填草稿 / 切客户 / 标已读（只读 + 弱副作用直接做）；
  **发送类只出「需确认」卡片，点了才真发，绝不自动发**
- 降级保底：模型挂了回退本地摘要，功能不删
- 话术引擎（talkEngine）：合规闸门 + 频控 + 待确认队列 + 回滚 + 提醒/归档

## 4. 发送（人工确认才发）
- 真发 send-live：填客户会话页 textarea → 点 #sendButton → 确认弹窗 → 点 #submitBtn
  真发，发完切回收件箱 + 自动重抓历史（让前端立即看到）
- 话术确认 send-confirm：走合规闸门 + 频控再发
- CDP 自动重连重试（withTargetOnce + retryCdp）

## 5. 网络与代理基建
- 网络体检 GET /api/console/network/health：出口 IP + 平台连通 + 归因
  （网络 / 平台 / CDP 卡住），页头 netChip 指示灯
- IPDeep 代理池 v1：随机数变体、90 分钟粘性、30 分钟冷却、事件驱动换 IP
  （proxy/pool、proxy/rotate(dryRun)、pool/expand、pool/sticky、health-rotate），
  页头「换 IP」按钮（先 dryRun 确认槽位 → 再执行 → 15s 自动体检）

## 6. 账号 / 配置
- 账号信息编辑 + 资料覆盖、见面地址管理（consolePrefs / accountInfo）
- 模型管理：多模型增删改查 + 激活 + 测试（model-status / models）
- 指标漏斗（metrics）、规则与回滚（rules / rules/rollback）、审计（audit）、引流私域（private-domain）
- 进程守护：SIGTERM / SIGINT 优雅退出

## 7. 底层能力（支撑上面）
- ichigoDeepScrape：出会窗口 CDP 抓取（收件箱/历史/资料）+ 真发 + 切收件箱 + 网络体检
- liveScanner：实时扫出会窗口；ichigoCache：三层缓存；ichigo194964：出会页面表达式
- db/store（SQLite）：客户 / 画像 / 会话 / 规则 / LeadEvent；leadScoring、recommender、dedup、profileExtractor
- aiService / translator / translationCache：LLM 翻译 + 规则兜底 + 内容寻址缓存
- bitbrowser / devtools：比特浏览器 CDP 连接管理

## 8. 入口
- 主控制台：/ichigo-console（ichigo-console.html，100KB+ 单页）
- 卡片式控制台：/console（console.html + console.js，另一套视图）
- 启动：start-console.bat / start-console.js；停止：stop-console.bat
